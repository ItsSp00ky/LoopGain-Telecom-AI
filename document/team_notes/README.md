# Team working notes

These files are how the team and its AI coding agents coordinated while building the platform.
They are kept as a record of the work; none of them is needed to run or review the code.

| File | What |
|---|---|
| `prepaid_churn_TICKETS.md` | The customer module's tickets, findings and the handoff written at the end of each session |
| `prepaid_churn_session_log.md` | The long working sessions, newest first: what was built, mistakes caught and how they were fixed |
| `prepaid_churn_ali_branch_merge.md` | The log of porting Ali's branch into the customer module |
| `prepaid_churn_CLAUDE.md`, `gis_CLAUDE.md` | The instructions the AI coding agents followed in each module |
| `CODE_REVIEW.md` | Ali's code review of the repository and its fixes |
| `gis_BRANCH_INTEGRATION_HANDOFF.md`, `gis_SUBMISSION_READINESS.md`, `gis_AHMED_SEPT29_REVIEW.md` | The GIS team's integration handoff, submission checklist and review of Ahmed's branch |

The decisions behind each module stay with its code, for example `prepaid_churn/docs/decisions.md`.
