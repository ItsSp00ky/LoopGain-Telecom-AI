# The operator Rates - Translation Session Transcript

## Local Call Rates (Standard Billing) / تسعيرة المكالمات المحلية للفوترة العادية

**Original (Arabic):**
تسعيرة المكالمات المحلية للفوترة العادية:
المشغل-المشغل: 90 درهمًا لأول 3 دقائق، ثم 50 درهمًا للدقيقة.
المشغل-المشغل الآخر: 90 درهمًا للدقيقة.
المشغل-خط ثابت: 40 درهمًا للدقيقة.

**Translation (English):**
Standard billing local call rates:
* **the operator to the operator:** 90 dirhams for the first 3 minutes, then 50 dirhams per minute.
* **the operator to the other Libyan operator:** 90 dirhams per minute.
* **the operator to Landline:** 40 dirhams per minute.

## SMS Rates / تسعيرة الرسائل القصيرة

**Original (Arabic):**
تسعيرة الرسائل القصيرة المحلية لباقة الفوترة من المشغل:-
المشغل-المشغل الآخر 50درهمًا / رسالة
المشغل-المشغل 50درهمًا / رسالة
تعرفة إرسال رسالة نصية لأي دولة خارج ليبيا: 250 درهم لكل رسالة نصية

**Translation (English):**
Local SMS rates for the operator billing package:
* **the operator to the other Libyan operator:** 50 dirhams / message
* **the operator to the operator:** 50 dirhams / message
* **Rate for sending a text message to any country outside Libya:** 250 dirhams per text message

---

## Data Rates (Bjawak Service) / خدمة بجوك

**Original (Arabic):**
سعر الميقا في خدمة بجوك هو 25 درهما لكل ميقا

**Translation (English):**
The price of a megabyte in the Bjawak service is 25 dirhams per megabyte.
